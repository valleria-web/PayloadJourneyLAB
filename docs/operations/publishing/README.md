# Publishing operations

This directory is the current destination for generated website validation artefacts.

New responsive captures and navigation-validation results belong under `website-validation/`. Historical V3 captures remain immutable in [`archive/website-evolution/v3/`](../../archive/website-evolution/v3/).

Generated validation artefacts support product and publication checks. They do not create governance or methodological authority.
